Chrome 窗口置顶 - 安装说明
===========================

重要说明：
- 本工具包含 Chrome 扩展 + 本地 PowerShell 辅助程序。
- AutoHotkey v2 可以保留，但本版本不依赖它；旧 AHK 置顶脚本请保持退出。
- 点击扩展图标时，辅助程序会对当前前台 Chrome 窗口切换置顶。
- 每个 Chrome 窗口可分别点击图标控制。
- 关闭辅助程序后，扩展无法继续切换置顶。

安装步骤：
1. 解压整个文件夹到固定位置，不要只移动 chrome-extension 子文件夹。
2. 右键 install-helper.bat，选择“以管理员身份运行”，按提示完成。
3. 双击 start-helper.bat。保持弹出的 PowerShell 窗口运行。
4. 在 Chrome 地址栏输入 chrome://extensions
5. 打开右上角“开发者模式”。
6. 点击“加载已解压的扩展程序”，选择本文件夹里的 chrome-extension 文件夹。
7. 将扩展固定到 Chrome 工具栏（拼图图标 -> 图钉）。

使用：
- 先点击想控制的 Chrome 窗口，使它成为当前窗口。
- 点击工具栏中的图钉扩展图标。
- 绿色 = 已置顶；灰色 = 未置顶。
- 再点击一次切换状态。

注意：
- 第一次安装会请求 Windows 管理员权限，仅用于注册本机回环监听地址。
- 辅助程序只监听 127.0.0.1，不对局域网开放。
- 这是本地辅助工具，不会读取或上传浏览记录。
- 如点击无反应，确认 start-helper.bat 对应窗口仍在运行。
